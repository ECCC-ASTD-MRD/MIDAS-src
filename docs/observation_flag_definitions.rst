Obervation Flag Definitions
===========================

The integer flag for each observation is stored at the body-level in the main
data object associated with the `obsSpaceData_mod` module in the `obs_flg` column.
Each bit of this integer has a separate meaning as defined in the table below.
The variable names listed in this table are defined in the module `obsFlags_mod`.
The bits are either read or modified using subroutines and functions from this module.

=============================== ====================================
Variable Name                   Description
=============================== ====================================
**flg_00** (not used in MIDAS)  DATA MODIFIED OR GEN BY ADE
**flg_01** (not used in MIDAS)  DATA EXCEEDS CLIMATE EXTREME
**flg_02erroneous**             ERRONEOUS DATA
**flg_03** (not used in MIDAS)  POSSIBLY ERRONEOUS DATA
**flg_04doubtful**              DOUBTFUL DATA
**flg_05** (not used in MIDAS)  INTERPOLATED DATA
**flg_06biasCorr**              CORRECTED DATA (BIAS CORRECTED)
**flg_07rejVarious**            SAT DATA REJECTED VARIOUS REASONS
**flg_08rejBlackL**             REJECTION BY BLACK LIST
**flg_09rejBgck**               REJECTION BY BACKGROUND CHECK
**flg_10rejIceGross**           GENERATED BY OI (ICE GROSS CHECK)
**flg_11rejSelect**             REJECTION BY SELECTION PROCESS
**flg_12seenByAnl**             DATA SEEN BY ANALYSIS
**flg_13ompLevel1**             O-P CHECK LEVEL 1
**flg_14ompLevel2**             O-P CHECK LEVEL 2
**flg_15ompLevel3**             O-P CHECK LEVEL 3
**flg_16rejOmP**                REJECTION BY O-P CHECK
**flg_17rejVarQC**              REJECTION BY VARQC
**flg_18rejOro**                REJECTION BY OROGRAPHY CHECK
**flg_19rejLandSea**            REJECTION BY LAND-SEA MASK
**flg_20** (not used in MIDAS)  AIRCRAFT DATA REJECTED BY TRACKQC
**flg_21rejTooHigh**            REJECTION DUE TO ABOVE MODEL TOP
**flg_22** (not used in MIDAS)  REJECTION BY RAW TO BURP
**flg_23cloudyObs**             CLOUD AFFECTED RADIANCE
**flg_24simulatObs**            SIMULATED OBSERVATION
**flg_25passiveObs**            PASSIVE OBSERVATION
=============================== ====================================
